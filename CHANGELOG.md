# Changelog

## Unreleased

- Fixed: a `Scroll` whose content wraps (a `Paragraph`) reaches its end. The content was measured at the full width and laid out beside the scrollbar, where it can be taller, so its last lines were out of reach.
- Fixed: a drag that leaves a clipping parent (`Clip`, `Scroll`) keeps following the pointer: `Resizable` edges, `Split` dividers, scrollbar thumbs, table column grips, `Moved` drag handles and text selection in `Field`, `Area` and `Code`. Nothing else is hit through the clip. If you call `CodeView.Update` or `TextArea.Update` directly, set `ctx.PointerX` and `ctx.PointerY` to the pointer along with `ctx.In`, as `view.Update` does, or drags read a stale position.
- Added: `view` gains `MarginOf`, `MarginXOf`, `MarginYOf`, `MarginLOf`, `MarginTOf`, `MarginROf`, `MarginBOf` and `MaxHOf`, which follow `ctx.Sizes` (a later literal, `MaxH(0)` or `Margin(0)` included, replaces them), and `(*view.El).MaxHeight`. `widget.DialogState` gains `Scroll`; a literal without field names must add it.
- Changed (behavior): a dialog (`Dialog`, `ResizableDialog`, `MessageDialog`) stays `dialogMargin` (40) off the window's edges, dragged or not, and is at most `dialogMaxH` (560) high, a height the app gives it (`H(700)`) included; `MaxH(0)`, another `MaxH` or `Margin` on the dialog replaces the limit. `ResizeState.H` stops at the same height.
- Changed (behavior): every dialog clips its content to its panel. A `MessageDialog` that reaches its limit scrolls its body text and content while its input and buttons stay in view; other dialogs scroll only where the app adds a `Scroll`. A drag that leaves a dialog still follows the pointer.
- Changed (behavior): a floating element's margins are now applied: it is placed, sized and dragged within its `Stack` less its margins. Before, a floating element ignored them.
- Changed (behavior): a `Resizable` whose element has a `MaxH` no longer lets `ResizeState.H` pass it.
- Added: theme files set the sizes of buttons, fields, sliders, split and column dividers, resizable edges, tables, `Code` and `Area`, and switches: `buttonPadX`, `fieldPadX`, `selectionInset`, `revealMargin`, `sliderW`, `sliderH`, `sliderTrack`, `sliderThumbW`, `sliderThumbH`, `sliderTick`, `sliderPad`, `dividerGrab`, `edgeReach`, `tableActionW`, `tableGripW`, `minColumnW`, `foldColW`, `monoTextLead`, `monoLinePad` and `switchInset`, each a field of `core.Sizes` with a role in `core`, a template scope name and a theme file key under `metrics.sizes`; `view` gains `DismissMarginOf`. The built-in themes lay out as before.
- Changed (behavior): a theme's `leading` also spaces the rows of `Code` and `Area` (`monoLinePad` is 2 units plus the leading, unless pinned). The built-in themes have no leading.
- Breaking: `widget.MinColumnPx` is removed. Read `ctx.Sizes.MinColumnW`.
- Breaking: `(*widget.TextField).Reveal` takes the margin kept beyond the cursor as a third argument. `Field` passes `ctx.Sizes.RevealMargin`; for the old value pass `core.DefaultSizes().RevealMargin` (12).
- Added: theme files set the sizes of scrollbars, `HScroll` arrows, menus, tooltips and toasts: `scrollbarW`, `minThumbLen`, `thumbInset`, `hscrollArrowW`, `menuMinW`, `menuMaxW`, `menuSepH`, `menuPad`, `menuHintH`, `menuRowPadX`, `menuIconW`, `menuShortcutGap`, `tipPadX`, `tipPadY`, `tipOffset`, `toastW`, `toastH`, `toastGap` and `toastMargin`, each a field of `core.Sizes`, a template scope name and a theme file key under `metrics.sizes`, with a role in `core` (`ScrollbarWOf`, `HScrollArrowWOf`, `ToastWOf`, ...). They follow `unit` and the spacing steps; the gap between a menu row's icon and label in `MenuWidth` now follows `looseGap`. The built-in themes lay out as before.
- Breaking: `widget.MenuMinW`, `MenuMaxW`, `MenuSepH` and `MenuPad` are removed. Read `ctx.Sizes.MenuMinW`, `.MenuMaxW`, `.MenuSepH` and `.MenuPad`, or use the role in an element option (`PadOf(core.MenuPadOf)`).
- Added: theme files set sizes. The optional `metrics` block has the knobs `unit`, `leading` and `steps`, and `sizes` pins any named size (`gutter`, `rowH`, ...). In Go they are `core.Theme.Metrics` (`core.Metrics`, `Metrics.Pin`, `core.Steps`). `core.Sizes` holds every shared size, the new scope names are `caretW`, `dialogW`, `dialogButtonMinW`, `dialogMargin` and `dialogMaxH`, and `core` gains a role for each named size (`GutterOf`, `NearGapOf`, `DialogWOf`, ...) and the bounds of the knobs (`MinUnit` to `MaxStep`), and `view` gains `PadOf`, `PadXOf`, `PadYOf`, `PadLOf`, `PadTOf`, `PadROf`, `PadBOf`, `GapOf`, `MinWOf` and `FloatAtOf`. The built-in themes lay out as before.
- Breaking: the exported size constants are gone, because a constant ignores the theme. In an element option write the role: `core.RowH` becomes `HOf(core.RowOf)`, `Pad(core.Gutter)` becomes `PadOf(core.GutterOf)`, `Gap(core.LooseGap)` becomes `GapOf(core.LooseGapOf)`. Where there is a `Ctx`, read `ctx.Sizes` (`core.NearGap` becomes `ctx.Sizes.NearGap`, `core.ToolbarH` `ctx.Sizes.Toolbar`, `core.CheckboxSize` `ctx.Sizes.Checkbox`); `core.DefaultSizes()` has the defaults. `BaseLine` and `BaseSmallLine` are `DefaultSizes().Line` and `.SmallLine`; `Unit` is `Metrics.Unit` (default 2); `StepHair` to `StepDialog` are `Sizes.Steps` (pixels) and `Metrics.Steps` (units). `widget.MenuRowH` is `widget.MenuRowHeight(ctx)` and `widget.MessageDialogW` is `WOf(core.DialogWOf)` or `ctx.Sizes.DialogW`.
- Breaking: `core.SizesFor` takes the theme's `Metrics` as a third argument; pass `core.Metrics{}` for the default rules.
- Changed (behavior): `theming.ParseTheme` rejects a theme file that is not one JSON object (`null`, data after the object) or whose `iconStroke` is outside 0 to 4, and keeps a base's `RadiusScale`, so a theme laid over square corners stays square.
- Breaking (behavior): the default text sizes are 15/13/14 px (interface/small/code), up from 14/12/13 (`theming.DefaultFontSize`, `DefaultSmallSize`, `DefaultCodeSize`). `core.BaseLine` is 17 and `core.BaseSmallLine` 15, so `RowH` (29), `CompactH`/`widget.MenuRowH` (25), `SlimH`, `LabelH`, `NoteH`, the bars, `IconBtnW`, `WordBtnW` and `CheckboxSize` (15) grow by 1 px, as does `DefaultSizes()`. Migrate: pass `theming.FontSizes{UI: 14, Small: 12, Code: 13}` to keep the old size.
- Added: `core.Caret` and `core.CaretShape` (`CaretBlock`, `CaretBar`, `CaretUnderline`), set through `Ctx.Caret`, choose the shape of the text caret and whether it stays steady (`Steady`); `core.CaretW` is the thickness of the bar and the underline.
- Breaking: the Ebitengine renderer moved to its own module `github.com/gascoigne-ai/uitoolkit/renderer/ebiten` (package `ebitenrender`); the root module no longer requires Ebitengine. Migrate: change the import path to `github.com/gascoigne-ai/uitoolkit/renderer/ebiten` and `go get` the renderer module. Tags are `vX.Y.Z` for the toolkit and `renderer/ebiten/vX.Y.Z` for the renderer.
- Removed: `core.Surface`, `Ctx.CanvasOf`, `Ctx.EbitenImage`, the old `Ctx.Clip(*ebiten.Image, Rect)`, `Sampler.Read`, `systeminfo.Ebiten` and `ebitenrender.ImageOf`. The toolkit packages no longer import Ebitengine.
- Renamed: `Ctx.ClipCanvas` is now `Ctx.Clip`. The `Ctx` draw calls and `view.Draw`, `DrawBelow` and `DrawFrom` take a `render.Canvas`. Use `sampler.Sample(ebitenrender.ReadInput())` for input.
- Changed: `engine.Binding.Key`, `IsModifierKey`, `IsFunctionKey` and `Matches` use `render.Key`; shortcut strings are unchanged. `systeminfo.Graphics` is an alias of the new `render.Graphics`, which names the renderer; `ebitenrender.ReadGraphics` fills it, and the System report shows a Renderer row first in Rendering.
- Removed: `examples/hello` and the tested examples of package `examples`; `go run ./examples/showcase` replaces them. `examples` is now a module of its own.
- Silent break: `*ebiten.Image` still satisfies `render.Image` (it has `Bounds`), so `widget.Image(img)` and `<image img>` compile but panic at draw with `render: image from another renderer`. Migrate with `ctx.Device.NewImage(img)`.
- Extracted from gascoigne-workshop as its own module, `github.com/gascoigne-ai/uitoolkit`. History before the move to `uitoolkit/` in the workshop is not carried over.
